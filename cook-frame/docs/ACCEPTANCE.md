# 验收用例（11 项）

被测应用：`iris.example.cookframe`（源码内 `APP_VER` = `v58e`）
环境：IrisView Developer Kit v1.0.0 · 640×480 抬头视口 · 模拟器文本输入 + 麦克风
口径：**界面**以模拟器实际渲染为准；**证据**优先引用运行日志（`dist/run.log`，同屏还有每 2 秒一次的 `COOK_PAINT` 快照）。这一版**没有开机页、没有状态徽章**，全靠画面本身判断。

> 自动化可复跑的部分：`node tools/mock-boot.js`（启动/选菜动画/生成/对话/收藏落盘 5 组）、
> `node tools/test-*.js`（9 套单测，共 200+ 项）。用例 10 的断服务部分需要人工执行。

## 用例 1 · 冷启动直接是菜单（两列、居中）

| 项 | 内容 |
|---|---|
| 前置 | 冷启动，无 `custom-dishes.json` |
| 操作 | 启动后什么都不说，等 2 秒 |
| 期望 | ① 没有开机动画、没有「说开始」这一步，**打开就是菜单**；② 主区标题「今天做什么菜？」；③ 菜名两列：左列 1-6、右列 7-11，两列关于画面中线对称（左列框 30~310，右列 330~610）；④ 顶栏 `菜单 · 1-11 · v58e`（只有一页时不显示页码）；⑤ 底栏「🎙 说编号或菜名 · 「不吃辣」避开辣菜」 |
| 证据 | `COOK_LOAD begin v58e` → `COOK_START_DONE v58e`、`COOK_PAINT mode=menu … main="今天做什么菜？"` |
| 不通过 | 停在「加载中」；出现点阵/「说开始」；两列不齐、右列贴边、菜名溢出框 |

## 用例 2 · 说编号选菜 → 选中动画 → 第 1 步

| 项 | 内容 |
|---|---|
| 前置 | 菜单页 |
| 操作 | 说（或文字框打）`三` |
| 期望 | ① 第 3 道放大到约 31 号、颜色提到近白、纵向浮到画面中心，其余菜淡出，全程 0.9 秒；② 结束进入做菜页：主步骤「第 1 步」+ 步骤说明；③ 右上角的输入方式标记与本次操作一致 |
| 证据 | `COOK_PICK begin idx=2 t0=…`、动画帧的 `row2:font` 逐步变大、`COOK_PAINT mode=cooking` |
| 不通过 | 直接跳转没有过场；选错行（说 3 进第 4 道）；动画后字号回不到 20 号 |

## 用例 3 · 说菜名选菜（只说半句也认）

| 项 | 内容 |
|---|---|
| 前置 | 菜单页 |
| 操作 | 说 `番茄炒蛋`；回菜单后再说 `番茄` |
| 期望 | ① 两次都进同一道菜（菜名包含匹配）；② 认不出时不说"没听懂"，而是提示「听到「X」· 没对上，请说对应编号 1-11」；③ 说 `推荐` 会挑一道并给出理由 |
| 证据 | `COOK_HANDLE final="番茄"`、`COOK_PICK begin idx=0` |
| 不通过 | 半句菜名要重说；把「番茄」认成别的菜；认不出时静默 |

## 用例 4 · 语音推进：下一步 / 上一步 / 跳过 / 停 / 继续

| 项 | 内容 |
|---|---|
| 前置 | 番茄炒蛋第 1 步，麦克风已授权 |
| 操作 | 依次说 `下一步` → `上一步` → `跳过` → `停` → `继续` |
| 期望 | ① 步骤 1→2→1→2；② `跳过` 与 `下一步` 同效但日志分开记；③ `停` 之后底栏只剩「说「继续」接着做」，此时说 `继续` 回到原步骤（不是下一步） |
| 证据 | `COOK_HANDLE final="下一步"`、`COOK_SKIP "跳过"`、`COOK_PAUSED`、`COOK_RESUMED` |
| 不通过 | 跳过把两步并成一步；暂停后任何口令都失效；恢复后步骤错位 |

## 用例 5 · 计时：起表 / 暂停 / 时间到

| 项 | 内容 |
|---|---|
| 前置 | 进入带计时的步骤（如「拍黄瓜」的 5 分钟那步） |
| 操作 | 说 `开始计时` → 等 3 秒 → 说 `停` → 说 `开始计时` |
| 期望 | ① 倒计时行出现 `⏱ 5:00` 并逐秒递减（`m:ss`）；② `停` 后数字冻结；③ 再起表接着走，不回到 5:00；④ 归零后提示「时间到 · 说「下一步」或「好了」继续」 |
| 证据 | `COOK_TIMER start … 300000ms`、`COOK_PAINT … timer="⏱ 4:57 …"` |
| 不通过 | 换步后计时不重置；格式不是 `m:ss`；时间到了不提示 |

## 用例 6 · 纠正与追问：主步骤不动

| 项 | 内容 |
|---|---|
| 前置 | 番茄炒蛋第 1 步 |
| 操作 A | 说 `太咸了` |
| 操作 B | 接着说 `加两勺生抽` |
| 操作 C | 说 `盐放多少` |
| 期望 | ① A：主步骤一个字不改，下方出补救建议（橙色），保留 10 分钟；② B：同一步上直接改成「已改为：2 勺」，**不丢 A 的回答**；③ C：答在下方，主步骤仍不动 |
| 证据 | `COOK_REPLY rescue …`、`COOK_REPLY answer …`、`COOK_PAINT … sub="💬 …"`、`COOK_PAINT … main="已改为：2 勺"` |
| 不通过 | 纠正把主步骤整段替换；答案只闪一帧；问一句把步骤顶走 |

## 用例 7 · 动态信息：进度 / 份量 / 火候

| 项 | 内容 |
|---|---|
| 前置 | 任意菜第 2 步 |
| 操作 | 说 `到哪了` → `两个人吃` → `火太大` |
| 期望 | ① `到哪了`：回「第 2 步 / 共 N 步 / 还剩约 M 分钟」；② `两个人吃`：把这一步的用量按两人份换算（原始量不变，答案里同时给原量与两份量）；③ `火太大`：给降火建议，不换步 |
| 证据 | `COOK_REPLY answer`（内容含「第 2 步」/「2 人份」）、步骤号不变 |
| 不通过 | 报错或答非所问；把份量换算写回菜谱数据 |

## 用例 8 · 不吃辣筛选 + 推荐

| 项 | 内容 |
|---|---|
| 前置 | 菜单页 |
| 操作 A | 说 `不吃辣` → 说 `推荐` |
| 操作 B | 说 `能吃辣` 恢复 |
| 期望 | ① 辣菜（麻婆豆腐）颜色变暗并在菜名后标「辣」，编号不变；② `推荐` 不再推辣菜；③ `能吃辣` 后恢复正常颜色与推荐范围 |
| 证据 | `COOK_PAINT mode=menu`（辣行颜色变暗）、推荐结果落在非辣菜上 |
| 不通过 | 标了「辣」但推荐仍推它；编号跟着变（导致说 9 吃到别的菜） |

## 用例 9 · 完成与收尾

| 项 | 内容 |
|---|---|
| 前置 | 任一道菜走到最后一步 |
| 操作 | 说 `完成了` → 按追问回答（`加进去` 或 `算了`）→ `不用`（不做下一道） |
| 期望 | ① 说 `完成了` 进收尾：先问要不要存进菜单（**只有库外菜问**，内置菜直接问下一道）；② 说 `加进去` 才存 —— 写进应用数据目录，日志 `saved`，下次启动排在菜单最前；③ 说 `算了` / `不用` 则这道菜**真的从菜单里消失**（日志 `COOK_TEMP drop`、`skip dropped=true`），收藏文件里也不会多出它；④ 含糊的 `好 / 要 / 可以` 只会再问一遍，不会误存；⑤ 收工总页显示「今天做了 N 道菜」与每道用时；⑥ 说 `再做一道` 回菜单 |
| 证据 | `COOK_WRAP start … canSave=true/false`、`COOK_WRAP saved "菜名" total=1` 或 `COOK_WRAP skip`、`COOK_WRAP summary dishes=1` |
| 不通过 | 越界崩溃；内置菜也被问收藏；收工页与「再做一道」互相抢 |

## 用例 10 · 异常与降级

| 项 | 内容 |
|---|---|
| 前置 | 停掉本机 `asr_server.py`（模拟"服务失败"，属注入测试） |
| 操作 A | 说 `下一步` |
| 操作 B | 文字框打 `下一步` |
| 操作 C | 恢复服务，对着麦克风说一小段背景噪音（锅响、椅子声） |
| 期望 | ① A：麦克风行写「⚠ 识别服务没连上 · 先启动 asr_server.py（5001）」，**应用不退出、当前步骤不丢**；② B：文字通道照常推进；③ C：噪音不会被当成一句话（这一版把起说门槛抬到 0.02、结论固定 `zh`，不会冒出日语字幕） |
| 证据 | `COOK_PAINT … mic="⚠ 识别服务没连上…"`、`COOK_TEXT "下一步"`、`COOK_ASR_CLOUD … language=zh` |
| 不通过 | 语音失败连带文字不可用；应用退出或重启；噪声被识别成外语并执行 |

## 用例 11 · 菜单翻页（超过 12 道）

| 项 | 内容 |
|---|---|
| 前置 | 菜单已有 13 道（11 道内置 + 2 道「加进去」的收藏），或刚生成了一道新菜 |
| 操作 | 说 `下一页` → `上一页` → 直接说第 2 页某道菜的名字 |
| 期望 | ① 第一页顶栏 `菜单 · 1/2 页 · 编号 1-12 · v58e`，第二页 `菜单 · 2/2 页 · 编号 1-1 · v58e`；② 每页的编号都从 1 开始（第 2 页第 1 道也说「1」）；③ 菜名可以跨页直选，不需要先翻页；④ 新生成的菜**追加到最后一页**，不会顶掉任何一道原有菜 |
| 证据 | `COOK_MENU page=1/2 n=13 onPage=12`、`COOK_MENU page=2/2 n=13 onPage=1`、`COOK_LLM ok … index=12`（index = 原长度，说明是追加） |
| 不通过 | 说「下一页」没反应；第 2 页编号接着 13 印（说不出来也认不出）；生成一道新菜后菜数还是 13（说明有人被顶掉了） |

## 复跑

```bash
node tools/mock-boot.js            # 端到端：启动 / 选菜动画 / 生成 / 对话 / 收藏落盘
COOK_MOCK_LLM=1 node tools/mock-boot.js   # 再加：生成不顶人 / 说「算了」撤掉 / 真翻页
node tools/test-engine.js          # 引擎解析（58 项）
node tools/test-rescue.js          # 救场链路（词表 + 引擎 + 答库）
node tools/test-wrap.js            # 收尾问答（54 项）
node tools/test-dynamic.js         # 进度 / 份量 / 火候
node tools/test-menu-list.js       # 菜单条目与编号
node tools/test-menu-page.js       # 菜单翻页（页数 / 页码 / 本页编号换算，25 项）
node tools/test-asr.js             # 云端识别结果校验（14 项）
node tools/test-asr-lang.js        # 外语/噪声拦截（16 项）
node tools/test-llm.js             # 大模型链路（26 项）
node tools/test-agent.js           # 联网问答（15 项）
node tools/latency.js              # 延迟（8 组 × 12 次）
node tools/check-secrets.js        # 密钥扫描（提交前必跑）
```
