录屏前先跑 `bash tools/pack.sh --run`，确认顶栏版本号是 `v58d`（和 git tag `cook-v58d` 对应）。

> 「自动更新」在这一版的具体含义：说 `加进去` 的那道菜会写进应用数据目录，**下次启动自动出现在菜单最前面**（日志 `COOK_RECIPE saved=N`），不需要改代码或重装。

## 必须拍到的八个点

1. **打开就是菜单**：没有开机动画、没有「说开始」，冷启动第一帧就是两列菜名
2. **两列对齐**：左列 1-6、右列 7-11，两列关于画面中线对称，菜名不裁字不贴边
3. **选中过场**：说 `三` 之后那道放大提亮、其余淡出（0.9 秒，能看清是我选的那道）
4. **一次纠正**：`太咸了` 只出建议、主步骤一个字不改；紧接着 `加两勺生抽` 改成「已改为：2 勺」
5. **动态信息**：`到哪了` 与 `两个人吃` 都答在步骤下方，步骤号不变
6. **暂停/恢复**：`停` 之后底栏只剩「说继续」，`继续` 回到原步骤
7. **菜单外的菜**：生成的菜直接进第 1 步（日志 `COOK_LLM ok 菜名 steps=N`）
8. **一次异常**：停掉识别服务后，麦克风行写「⚠ 识别服务没连上」，**文字框打 `下一步` 仍能推进**

## 录制

```bash
# 1) 保证是最新包
bash tools/pack.sh
# 2) 录屏（WSLg 下用 ffmpeg 抓模拟器窗口；或 Windows 侧 OBS 抓 WSLg 窗口）
ffmpeg -f x11grab -video_size 1280x800 -i :0 -t 120 -r 30 demo-$(date +%H%M).mp4
# 3) 录完把 demo-*.mp4 和截图放进提交包（不要放密钥、不要放 llm.json）
```
