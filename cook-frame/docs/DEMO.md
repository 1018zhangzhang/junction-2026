赛题要求：视频 ≤120 秒，必须包含**新需求**、**自动更新**、**一次异常处理或纠正**。
录屏前先跑 `bash tools/pack.sh --run`，确认左上角版本号与 git tag 一致。

## 必须拍到的十个点

1. 左上角状态徽章真的在换（`待命/处理中/待确认/完成/异常`）
2. 右上角 `输入 · 语音` / `输入 · 文本` 真的在换
3. 「大字 → 精简」两次连续重排（间隔不超过 10 秒，中间不重启）
4. 一次纠正（`太咸了` 或 `马婆豆腐 → 麻婆豆腐`）
5. 一次异常（停服务）后**文字仍能推进**
6. 生成菜停在 `[待确认]`，没有自动开做
7. **菜单滚动 + 时间备注**：说 `下一条` 光标下移、窗口跟着滚，黄字行显示「当前 N. 菜名 · 约 M 分」
8. **冷启动的点阵动画**（至少 3 秒动着的画面）+ 说 `开始` 之后才进菜单（这一屏是「待命」状态的证据）
9. **字号舒适档**：`看不清` 前后对比底栏/麦克风行（14 → 16 号），主步骤与菜名不变（`COOK_FONT` 日志可对帧）
10. **忌口记忆**：说 `我不吃葱` 之后，含葱的菜名后出现 `（含葱）`；再说 `我有什么忌口` 能复述（`COOK_TASTE` 日志可对帧）

## 录制

```bash
# 1) 保证是最新包
bash tools/pack.sh
# 2) 录屏（WSLg 下用 ffmpeg 抓模拟器窗口；或 Windows 侧 OBS 抓 WSLg 窗口）
ffmpeg -f x11grab -video_size 1280x800 -i :0 -t 120 -r 30 demo-$(date +%H%M).mp4
# 3) 录完把 demo-*.mp4 和截图放进提交包（不要放密钥、不要放 llm.json）
```
